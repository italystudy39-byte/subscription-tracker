# Трекер подписок

Full-stack приложение для учёта платных подписок: сколько уходит в месяц и год, на какие категории и что спишется в ближайшие дни. Все данные хранятся локально в файле SQLite.

- Требования к продукту: [PRD.md](PRD.md)
- Техническая спецификация: [SPEC.md](SPEC.md)

**Стек:** React 18 + Vite 5 + React Router · Node.js + Express 4 · SQLite (better-sqlite3). Валидация и расчёты лежат в `shared/` и общие для клиента и сервера.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install          # один раз
npm run seed         # необязательно: 10 демо-подписок в пустую базу
npm run dev          # разработка: http://localhost:5173 (API на :3001)
```

Production-режим, всё на одном порту:

```bash
npm run build
npm start            # http://localhost:3001
```

Тесты (15 шт.: расчёты, даты, валидация, REST API):

```bash
npm test
```

Настройки через переменные окружения: `PORT` (по умолчанию 3001) и `DB_PATH` (по умолчанию `data/subscriptions.db`). База и таблицы создаются автоматически при первом запуске. Чтобы начать с чистого листа, удалите папку `data/`.

> Если `npm install` падает на сборке better-sqlite3 (редко, обычно на очень новой версии Node), поставьте Node LTS или установите инструменты сборки: на Windows это «Desktop development with C++» из Visual Studio Build Tools, на macOS `xcode-select --install`.

## Что умеет

| Экран | Путь | Что там |
|---|---|---|
| Дашборд | `/` | Расходы в месяц и год в основной валюте, число активных, ближайшее списание, расходы по категориям, списания на 7 дней |
| Подписки | `/subscriptions` | Таблица (десктоп) или карточки (мобильный), фильтры по категории и статусу, сохраняются в URL |
| Форма | `/subscriptions/new`, `/subscriptions/:id/edit` | Название, категория, стоимость, валюта, периодичность, дата списания, статус, заметка; расчёт «в месяц / в год» на лету; удаление с подтверждением |
| Списания | `/upcoming` | Все списания на 7, 30 или 90 дней с итоговой суммой; сегодня и завтра выделены красным, до 3 дней жёлтым |
| Настройки | `/settings` | Основная валюта и курсы пересчёта (11 валют) |

Правила расчёта:
- В итоги попадают только **активные** подписки.
- Еженедельная подписка в месяц = сумма × 52 / 12, годовая = сумма / 12.
- Валюты пересчитываются через USD по курсам из настроек. Курсы не подтягиваются из интернета, их можно поправить вручную.
- Если дата списания уже прошла, приложение само показывает следующую по периодичности. Подписка на 31-е число в коротких месяцах списывается в последний день месяца.

## Структура

```
shared/   constants.js, validation.js, money.js, dates.js  (общий код)
server/   index.js, app.js (API), db.js (схема), repo.js (SQL), stats.js (итоги)
client/   index.html, src/ (App, pages/, components/, styles.css)
tests/    shared.test.js, api.test.js
scripts/  seed.js
```

API описан в [SPEC.md](SPEC.md#4-rest-api).

## Как проверялось

Приложение запускалось локально (`npm run build && npm start`) и прогонялось в Chromium через Playwright на ширине 1280 px и 375 px:

- пустые состояния дашборда, списка и списаний;
- отправка пустой формы и суммы с 3 знаками после запятой: ошибки у полей, фокус на первом ошибочном поле;
- добавление через форму, изменение статуса, удаление с подтверждением;
- фильтры по статусу и категории, пустой результат и сброс;
- смена основной валюты на USD с некорректным курсом (ошибка) и корректным (итоги пересчитались);
- несуществующая подписка (404) и недоступный сервер (сообщение и кнопка «Повторить»);
- отсутствие горизонтального скролла на всех экранах.

Итоги на дашборде сверены с ручным расчётом по формулам выше. Скриншоты лежат в [screenshots/](screenshots/).
